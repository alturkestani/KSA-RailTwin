# KSA rail network from OSM and published facts

Input: `data/osm/gcc-states-latest.osm.pbf` (symlink to TrafficTwin's copy; Geofabrik, ODbL, replication 2026-10-14; row in `cities/ksa/sources.yaml`). Never re-download; never write into `data/osm/`.

## Extraction
1. Clip to Saudi Arabia if needed: `osmium extract -p cities/ksa/zones/ksa.poly data/osm/gcc-states-latest.osm.pbf -o data/ksa/osm/ksa.osm.pbf` (osmium-tool via brew; record the version). Check free disk first (the clip is a few hundred MB).
2. Rail objects: `osmium tags-filter data/ksa/osm/ksa.osm.pbf r/route=train,railway w/railway=rail,light_rail,subway,construction,proposed,disused,abandoned n/railway=station,halt -o data/ksa/osm/ksa-rail.osm.pbf`, then `uv run python -m rail.osm extract --pbf data/ksa/osm/ksa-rail.osm.pbf --out cities/ksa/lines/osm_raw.geojson` (pyosmium or OSMnx; record which).
3. Also keep `railway=abandoned` (the Hejaz Railway) for the history chapter, tagged `layer: historical`.

## Layer tagging (every feature)
| layer | OSM evidence | published evidence required |
|---|---|---|
| `existing` | `railway=rail` in service, `route=train` relations | SAR/HHR line list and station list (date sampled) |
| `committed` | `railway=construction` or `proposed` with a credible operator | an official announcement, tender or contract (MEED/ENR/SPA/SAR) with date; `status` = announced / design / procurement / construction |
| `hypothetical` | none | generated by `corridor-generator` only |
| `historical` | `railway=abandoned/disused` | archival source |
Planned lines are "announced/planned" with source and date, never "existing" (rule 5). Where OSM and the operator disagree (alignment, station names), keep both with `conflict: true` and note it in `docs/data-sources.md`.

## Digitising planned lines
Landbridge (Riyadh–Jeddah, ~950 km; stations incl. Al-Jumum), Saudi GCC section (Al-Khafji–Dammam–Al-Batha, ~672 km), Riyadh Rail Link and any others found: digitise an indicative alignment along published corridor descriptions, store `uncertainty_km` (positional uncertainty, e.g. 10–30 km) and `source: S-xxx` per feature; station sites get `site_status: published / inferred` (Al-Jumum: planned station, exact site to locate; cite meedprojects.com pid=114639).

## Output files (`cities/ksa/lines/`)
`existing.geojson`, `committed.geojson`, `historical.geojson`, `stations.geojson` (with `layer`, `operator`, `opened`, `source`), one `line-yaml` file per line under `cities/ksa/lines/*.yaml`, and `README.md` with the credit "© OpenStreetMap contributors (ODbL 1.0)" plus the operator sources. Every map rendered from these files prints the OSM credit and the layer legend.

## Checks
`uv run python -m rail.osm validate cities/ksa/lines/` — every feature has `layer`, `source`, `accessed`; committed features have `status` and `uncertainty_km`; no feature with `layer: existing` lacks an operator source; station count per line matches the line YAML.
