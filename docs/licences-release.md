# Licence and openness register: release note (R8)

**What this is.** The release-compatibility check of the licence and openness register (`licence-register` skill; PROJECT.md rule 12) before any public or commercial release of KSA Rail Twin (report, policy brief, executive summaries, figures, dashboard, code and committed tables). It consolidates `docs/licences.csv` (canonical; `docs/licences.md` is generated from it and `uv run python -m common.licences check` reports 0 differing rows) and every track fragment `docs/licences-*.csv` present when this note was generated. **Nothing here resolves a conflict:** every carried flag is listed as a release blocker to clear, and Tariq decides each one. Nothing is published from this repository (rule 7); CP6 and CP7 come first.

**How the table is built.** `uv run python -m common.sources licences-release --write docs/licences-release.md` regenerates the table between the GENERATED markers from the register files, so a changed register row changes this note. The release status of each row follows one rule set (`common/sources.py`, `release_status`), applied in this order:

| status | rule |
|---|---|
| **BLOCKER** | one of the named carried flags below (B1–B9); or the register marks the row blocked; or commercial use is N (non-commercial terms); or `commercial use`, `open` or `licence` says unclear; or the row is flagged (status, an explicit `FLAG:` in the obligations, or an approval that says flag / decide before release); or the item is not open and no approval is recorded |
| NOT IN RELEASE | the register says superseded, not used, not available, unreachable, or planned (not yet used); any licence issue must be cleared before first use. A generic row superseded by a more specific versioned row (for example UN WPP, GHSL, WorldPop, citypopulation.de) names that row in its reason; the versioned row carries the release status |
| VERIFY | used, licence believed open, but the register says the licence or terms are still to confirm |
| OBLIGATIONS | compatible with the release if the stated attribution, notice or share-alike obligation is met |
| COMPATIBLE | open, commercial use allowed, no obligation beyond keeping the licence notice |

## 3. Obligations that attach to a release (if the blockers clear)

- **OpenStreetMap (ODbL-1.0):** "© OpenStreetMap contributors, https://www.openstreetmap.org/copyright" on every map, figure and dashboard view that shows OSM-derived geometry; share-alike on any derived database (see B7).
- **GASTAT:** "Source: General Authority for Statistics (GASTAT)"; derived tables marked as derived and not presented as official GASTAT statistics.
- **Terrain and imagery:** the Copernicus DEM GLO-30 credit line exactly as in the register; "Contains modified Copernicus Sentinel data" for Sentinel-2 and ESA WorldCover; NASA JPL citation for SRTM.
- **Population grids and statistics:** WorldPop, GHS-POP R2023A (European Commission JRC), UN WPP 2024 and WUP 2025 (modified), World Bank WDI (CC BY 4.0), Microsoft Global ML Building Footprints (CDLA-Permissive-2.0 text or link when the data are shared).
- **UK public-sector material (TAG, Green Book, DESNZ, NTS):** "Contains public sector information licensed under the Open Government Licence v3.0".
- **Dashboard basemap (OpenFreeMap, R8 rows of `docs/licences.csv`):** "© OpenMapTiles; Data from OpenStreetMap" visible on every dashboard map and screenshot, also in print or video; the browser fetches tiles from a public external service at view time (no project data is sent; offline fallback `?basemap=none`). The dashboard API fixtures (`tests/fixtures/api`) carry OSM-derived geometry and inherit the B7 question.
- **Report and deck figures:** Noto Sans and Noto Naskh Arabic TTF files ship in `common/fonts/` with their OFL text (R8 figure rows of `docs/licences.csv`); OFL-1.1 bars selling the fonts on their own and requires renaming modified versions.
- **Fonts:** Noto Sans Arabic / Noto Naskh Arabic, IBM Plex Sans Arabic and Amiri are OFL-1.1 in the register (no selling the fonts on their own; reserved font names); their rows are still "planned; unverified", so the font files actually shipped in a release need their rows confirmed.
- **Code:** Apache-2.0 for the repository; `NOTICE` mirrors the register; GPL tools (osmium-tool, ffmpeg builds) are called as external programs and not redistributed: bundling any binary would need a fresh check.
- **Share-alike interactions:** ODbL (OSM-derived databases) and CC BY-SA 4.0 (UNESCO whc001, Wikipedia-derived lists) are different share-alike licences; a database combining both may not satisfy both at once. Listed as a conflict to decide (B3, B6, B7), not resolved here.
