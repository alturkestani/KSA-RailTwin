# Assumptions: STUDY_EXTRA_TRAVEL (extra domestic trips; visitor and land-entry effects)

This is the study's register, in the `docs/assumptions.md` row format. It sits beside the study on purpose: `common.report build` reads `docs/assumptions*.md` and `docs/sources/index.csv` into the R8 report annexes, and this study must not change any R8 reader-facing file. The study's sources are in `docs/sources/study-extra-travel.csv` for the same reason. If Tariq wants an integration later, it merges both. Constants live in `cities/ksa/assumptions/extra_travel_study.yaml`.

**Labels:** synthetic demand, uncalibrated: scenario comparison, not a forecast. Not the official ranking.

**Frozen central values not touched:** A-demand-012…015 (trip rates), A-demand-016 and A-demand-019 (pilgrimage totals), A-intl-001 (entry-port shares), A-intl-003 (fitted rail share 0.0286). The variants below exist only on the study path.
