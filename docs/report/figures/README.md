# Report figures (R8)

Every `fig*.svg` / `fig*.png` here is rendered from run outputs and registers by `common/figures.py`; none is hand-drawn and no result number is typed into the code. The `dashboard-*.png` screenshots in this folder belong to the dashboard track and are not built by this module.

**Build (deterministic, byte-identical on rebuild):**

```
uv run python -m common.figures build --out docs/report/figures/ --deck docs/deck-figures/ --handoff logs/r8-figures-handoff.md
```

`--seed` (default 1) seeds the only random element (the jitter of the benchmark strip plot). SVGs carry no date (`metadata Date None`) and a fixed `svg.hashsalt`; text is drawn as glyph paths with the string kept as an SVG comment and in the SVG description, so the labels are searchable. Fonts: Noto Sans and Noto Naskh Arabic (OFL-1.1) from `common/fonts/`, registered at run time (`docs/licences.md`, R8 figure rows).

**On every figure:** the label "synthetic demand, uncalibrated: scenario comparison, not a forecast" (`common.labels.LABEL`); its provenance, read from the runs' `meta.json` (run family, code version, seed): "judge v3 d9fef643… · seed 1" appears only on figures built from judge v3 runs (or from the R7 funding engine on judge v3 scores), while R5 CBA, R2 screening, R4/R5 access and benchmark-register figures name their own runs; the source run ids; and, where a length, cost, travel time or ridership is shown, `common.labels.ALIGNMENT_LIMITATION`. Maps carry "© OpenStreetMap contributors (ODbL)" and a legend with every rail layer (existing / committed or under procurement, announced/planned / historical / hypothetical, ours). Screening figures also carry "screening input, not a forecast". Modelled results are P10/P50/P90 ranges; the isochrones are a deterministic network measure and say so.

**Decision framing (prompts/R8.md, R7-checkpoint answers):** S6-L2 = central case; S6-L1 = upside case carrying the Al-Kharj spur's P90 cost risk; S6-L3 = reach alternative; all against S1. S6-L4 and S6-L5 appear only on `fig08` (labelled "trade-off illustration only: no recommendation") and as unlabelled points on `fig07`. S6-L6 (R8_L6_PANEL, Tariq 6 Nov 2026) is a connectivity comparison ("comparison layout, not the recommended programme"), not a search-front point: it is read from `runs/r6/l6/score/S6-L6.csv` (never from `runs/r6/top5/`), drawn as a labelled open diamond on `fig08`, not drawn on `fig07` (caption only), and shown on `fig16`, which embeds the existing connected-system map `s6-l6-connected-map.png` (written by `optimise.connect map` at S6_L6_CONNECTED) unchanged beside the S6-L6 scorecard. Frozen alignment weights v1 only (`cities/ksa/alignments/`; never `alignments-v2`, `top5-v2` or `runs/r7-v2`).

**Index:** `figures-index.csv` (stem, title_en, caption = one line on what is drawn, sources = the exact files read, provenance, labels_present, files): the report captions should be generated from it. The build refuses to save a figure whose text extends beyond the canvas (`clipped_texts`). Numbers each figure shows, with their source files and the choices made where the inputs were ambiguous: `logs/r8-figures-handoff.md` (regenerated by the build).

## Arabic summary render check (FIX_R8 item 4)

`executive-summary.ar.html` is `docs/executive-summary.ar.md` rendered right to left (`lang="ar"`, `dir="rtl"`, Noto Naskh Arabic linked from `common/fonts/`); `ar-render-page1.png` is the first screen of it (900 × 1273 CSS px at 1.5×) and `ar-render-table.png` the options table cropped from the full-page capture by the table rule colour. Captured with the approved local headless Google Chrome; the PDF and the full-page capture stay under `runs/fix-r8/ar-render/` (gitignored). Rebuild:

```
uv run python -m common.ar_render html docs/executive-summary.ar.md docs/report/figures/executive-summary.ar.html
uv run python -m common.ar_render pdf docs/report/figures/executive-summary.ar.html runs/fix-r8/ar-render/executive-summary.ar.pdf
uv run python -m common.ar_render shot docs/report/figures/executive-summary.ar.html docs/report/figures/ar-render-page1.png
uv run python -m common.ar_render shot docs/report/figures/executive-summary.ar.html runs/fix-r8/ar-render/full.png --height 4400
uv run python -m common.ar_render crop-table runs/fix-r8/ar-render/full.png docs/report/figures/ar-render-table.png
uv run python -m common.ar_render bidi-probe docs/report/figures/executive-summary.ar.html
```

The typography rule (numeric runs in left-to-right isolates) is in `docs/glossary.ar.md` §typography. The Arabic text is a draft pending Tariq's native review.
