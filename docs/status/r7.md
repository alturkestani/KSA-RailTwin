**Decisions (builder, recorded here)**
- D-r7-01: corridor-level figures are standalone judge v3 runs at the CP7 phase; three new 2050 runs were scored with the frozen judge (the Al-Kharj run reproduces the library's 2050 robust NPV of 4,309). Standalone values do not add up to the layouts, so the programme figures use the layout scores.
- D-r7-02: the judge stores only P10/P50/P90 summaries. R7 approximates quantiles of the PV components (A-fund-107), uses a lognormal tail through P50/P90 (A-fund-108) and level annual equivalents (A-fund-109). Exact draws would need a judge change, which is not allowed.
- D-r7-03: FIRR is not reported for the layouts (the judge stores no annual flows); the farebox ratio PV fares ÷ PV opex and renewals is reported instead.
- D-r7-04: the VfM test follows the Green Book PSC logic (S-fund-024; the NCP method is unclear). The PSC is not charged a financing cost; flat 5 % and the sovereign real rate are reported as sensitivities, and the sign is unchanged.
- D-r7-05: termination compensation is a memorandum item (PFRAM worst case and × A-fund-006), not added to the net fiscal cost.
- D-r7-06: new source track file `docs/sources/r7-fund.csv` (S-fund-r7-001, NAO 2018) and register ids A-fund-101…109. A-fund-002/006/007/008 are set (R1d had "not set (R7)").
- D-r7-07: `docs/STATUS.md` is not owned by this track; integration copies this block there.
- D-r7-09 (verify-R7 pass 1, F1): who sets passenger fares is now an unclear legal item (`fare_setting_authority`); Railway Law Art. 18 is cited only for usage (access) fees under use agreements. Allocation rules v1.1 and every matrix regenerated.

Layouts use the judge's fiscal cost at every horizon; corridors (standalone runs store 60 y only) use the cash-flow engine at every horizon, with the judge's 60-year fiscal cost P50 printed next to it as a cross-check (e.g. Al-Kharj engine 7,523 vs judge 7,137).
