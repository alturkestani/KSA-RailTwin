Row kept with `screened: false`, no population, no distances; the lat/lon is the governorate polygon centroid, not a settlement. Nothing chosen by guessing.

- Badr seat: OSM node 1237968680 (Badr Hunayn), matched to primary 'Badr' 30,494; the pilot's way 87175609 has the same population and is recorded as the alternative (A-madinah-007).

- Economic roles tie to rows through R1a economic nodes (`nearest_town` = the row's town); Badr and Khaybar roles use the pilot sources S-madinah-010/011 (secondary; search summaries).
